## 第一阶段：面向对象深入（第1-2周）

### 📖 学习目标
- 深入理解继承、多态、虚函数
- 掌握访问控制和封装原则
- 理解构造函数和析构函数的调用顺序

### 🎯 核心知识点

#### 1.1 继承与多态
```cpp
// 基础：单继承
class Device {
protected:
    std::string name_;
    bool isOnline_;

public:
    Device(const std::string& name) : name_(name), isOnline_(false) {}
    virtual ~Device() = default;  // 虚析构函数很重要！

    // 纯虚函数：强制子类实现
    virtual bool connect() = 0;
    virtual void disconnect() = 0;

    // 虚函数：可以被重写
    virtual std::string getStatus() const {
        return isOnline_ ? "Online" : "Offline";
    }
};

// 派生类：EFEM设备
class EfemDevice : public Device {
private:
    int doorCount_;

public:
    EfemDevice(const std::string& name, int doors)
        : Device(name), doorCount_(doors) {}

    // 重写虚函数
    bool connect() override {
        // 连接逻辑
        isOnline_ = true;
        return true;
    }

    void disconnect() override {
        isOnline_ = false;
    }

    // 重写并扩展
    std::string getStatus() const override {
        return Device::getStatus() + ", Doors: " + std::to_string(doorCount_);
    }
};
```

**关键概念**：
- `virtual`：允许动态绑定（运行时多态）
- `override`：明确标记重写，编译器会检查
- `= 0`：纯虚函数，类变成抽象类
- 虚析构函数：防止内存泄漏

#### 1.2 访问控制
```cpp
class RecipeManager {
private:
    // 只有类内部能访问
    std::map<int, Recipe> recipes_;
    std::mutex mutex_;  // 线程安全

protected:
    // 子类可以访问
    void validateRecipe(const Recipe& recipe) {
        // 验证逻辑
    }

public:
    // 外部接口
    bool loadRecipe(int id);
    bool saveRecipe(const Recipe& recipe);
};
```

**设计原则**：
- **最小权限原则**：默认用`private`，必要时才用`public`
- **接口与实现分离**：公开接口稳定，私有实现可变
- **保护不变式**：用private保护内部状态一致性

#### 1.3 构造与析构顺序
```cpp
class Base {
public:
    Base() { std::cout << "Base构造\n"; }
    virtual ~Base() { std::cout << "Base析构\n"; }
};

class Derived : public Base {
private:
    std::string data_;

public:
    Derived() : Base(), data_("test") {
        std::cout << "Derived构造\n";
    }

    ~Derived() override {
        std::cout << "Derived析构\n";
    }
};

// 输出顺序：
// 构造: Base → Derived
// 析构: Derived → Base (反向)
```

## 第二阶段：内存管理与RAII（第3-4周）

### 📖 学习目标
- 理解栈内存与堆内存的区别
- 掌握智能指针的使用
- 理解RAII（资源获取即初始化）原则

### 🎯 核心知识点

#### 2.1 内存管理基础
```cpp
// 栈内存：自动管理，作用域结束自动释放
void stackExample() {
    int x = 10;           // 栈上分配
    std::string s = "hi"; // 栈上对象，内部可能有堆内存
}  // x和s自动销毁

// 堆内存：手动管理（不推荐裸指针）
void heapExample() {
    int* p = new int(10);  // 堆上分配
    // ... 使用p
    delete p;              // 必须手动释放！
    p = nullptr;           // 防止悬空指针
}

// 问题：如果中间抛异常，delete不会执行 → 内存泄漏
```

#### 2.2 智能指针（现代C++推荐）
```cpp
#include <memory>

// 1. unique_ptr：独占所有权
void uniquePtrExample() {
    std::unique_ptr<Device> device = std::make_unique<EfemDevice>("EFEM1", 2);
    device->connect();
    // 作用域结束，自动delete，无需手动释放
}

// 2. shared_ptr：共享所有权（引用计数）
class ConnectionPool {
private:
    std::vector<std::shared_ptr<QTcpSocket>> connections_;

public:
    std::shared_ptr<QTcpSocket> getConnection() {
        auto conn = std::make_shared<QTcpSocket>();
        connections_.push_back(conn);
        return conn;  // 可以安全返回，引用计数+1
    }
};

// 3. weak_ptr：打破循环引用
class Worker;
class Manager {
    std::vector<std::shared_ptr<Worker>> workers_;
};

class Worker {
    std::weak_ptr<Manager> manager_;  // 不增加引用计数
};
```

**使用原则**：
- **优先使用`unique_ptr`**：明确所有权，性能最好
- **需要共享时用`shared_ptr`**：多个对象共享资源
- **避免循环引用用`weak_ptr`**：观察者模式
- **避免裸指针**：除非与C API交互

#### 2.3 RAII原则
```cpp
// RAII: Resource Acquisition Is Initialization
// 资源的生命周期与对象绑定

// 错误示例：手动管理
void badExample() {
    std::mutex mtx;
    mtx.lock();
    // ... 如果这里抛异常，锁永远不会释放！
    mtx.unlock();
}

// 正确示例：RAII
void goodExample() {
    std::mutex mtx;
    std::lock_guard<std::mutex> lock(mtx);  // 构造时加锁
    // ... 即使抛异常，析构函数也会自动解锁
}  // 作用域结束，自动解锁

// 自定义RAII类
class FileHandle {
private:
    FILE* file_;

public:
    FileHandle(const char* filename) {
        file_ = fopen(filename, "r");
        if (!file_) throw std::runtime_error("Failed to open file");
    }

    ~FileHandle() {
        if (file_) fclose(file_);  // 自动关闭
    }

    // 禁止拷贝
    FileHandle(const FileHandle&) = delete;
    FileHandle& operator=(const FileHandle&) = delete;

    FILE* get() { return file_; }
};
```

## 第三阶段：STL标准库（第5-6周）

### 📖 学习目标
- 掌握常用容器的特性和使用场景
- 理解迭代器的概念
- 学会使用STL算法

### 🎯 核心知识点

#### 3.1 顺序容器
```cpp
#include <vector>
#include <list>
#include <deque>

// vector：动态数组，连续内存
std::vector<Recipe> recipes;
recipes.push_back(recipe);           // 尾部添加
recipes.reserve(100);                // 预分配，避免多次扩容
auto& first = recipes[0];            // 随机访问 O(1)
recipes.erase(recipes.begin() + 2);  // 删除第3个元素

// list：双向链表
std::list<Task> taskQueue;
taskQueue.push_front(task);  // 头部插入 O(1)
taskQueue.push_back(task);   // 尾部插入 O(1)
// 适合频繁插入删除，但不支持随机访问

// deque：双端队列
std::deque<Event> eventQueue;
eventQueue.push_front(event);  // 两端都快
eventQueue.push_back(event);
```

**选择原则**：
- **默认用`vector`**：性能最好，缓存友好
- **频繁头部插入用`deque`**
- **频繁中间插入删除用`list`**

#### 3.2 关联容器
```cpp
#include <map>
#include <unordered_map>
#include <set>

// map：有序键值对（红黑树）
std::map<int, Recipe> recipeMap;
recipeMap[1] = recipe;           // 插入或更新
recipeMap.insert({2, recipe2});  // 插入
if (recipeMap.count(1)) {        // 检查存在
    auto& r = recipeMap.at(1);   // 安全访问（会检查）
}

// unordered_map：哈希表，更快
std::unordered_map<std::string, Device*> deviceMap;
deviceMap["EFEM1"] = efemDevice;
// 查找 O(1) vs map的 O(log n)

// set：有序集合（去重）
std::set<int> recipeIds;
recipeIds.insert(1);
recipeIds.insert(1);  // 重复插入无效
// size() == 1
```

**项目中的应用**：
```cpp
// RecipeManager.h 中可以这样设计
class RecipeManager {
private:
    std::unordered_map<int, Recipe> recipes_;  // 快速查找
    std::set<int> activeRecipeIds_;            // 去重
    std::vector<RecipeStep> currentSteps_;     // 顺序访问
};
```

#### 3.3 STL算法
```cpp
#include <algorithm>
#include <numeric>

std::vector<int> numbers = {5, 2, 8, 1, 9};

// 排序
std::sort(numbers.begin(), numbers.end());
// 结果: {1, 2, 5, 8, 9}

// 查找
auto it = std::find(numbers.begin(), numbers.end(), 5);
if (it != numbers.end()) {
    std::cout << "Found at index: " << std::distance(numbers.begin(), it);
}

// 条件查找
auto it2 = std::find_if(numbers.begin(), numbers.end(),
    [](int n) { return n > 5; });  // 找第一个>5的

// 统计
int count = std::count_if(numbers.begin(), numbers.end(),
    [](int n) { return n % 2 == 0; });  // 偶数个数

// 转换
std::vector<int> doubled(numbers.size());
std::transform(numbers.begin(), numbers.end(), doubled.begin(),
    [](int n) { return n * 2; });

// 累加
int sum = std::accumulate(numbers.begin(), numbers.end(), 0);
```

### 📖 学习目标
- 掌握Lambda表达式
- 理解移动语义
- 学会使用auto和范围for

### 🎯 核心知识点

#### 4.1 Lambda表达式
```cpp
// 基本语法: [捕获列表](参数) -> 返回类型 { 函数体 }

// 1. 简单lambda
auto add = [](int a, int b) { return a + b; };
int result = add(3, 5);  // 8

// 2. 捕获外部变量
int threshold = 10;
auto filter = [threshold](int n) { return n > threshold; };

// 3. 捕获方式
int x = 5;
[x]()     { /* 按值捕获x */ };
[&x]()    { /* 按引用捕获x */ };
[=]()     { /* 按值捕获所有 */ };
[&]()     { /* 按引用捕获所有 */ };
[this]()  { /* 捕获this指针 */ };

// 4. 在Qt信号槽中使用
connect(socket, &QTcpSocket::readyRead, this, [this]() {
    QByteArray data = socket->readAll();
    processData(data);
});

// 5. 在STL算法中使用
std::vector<Recipe> recipes;
auto it = std::find_if(recipes.begin(), recipes.end(),
    [](const Recipe& r) { return r.isActive(); });
```

#### 4.2 移动语义
```cpp
// 左值 vs 右值
int x = 10;      // x是左值（有名字，可取地址）
int y = x + 5;   // x+5是右值（临时值）

// 移动构造函数
class Buffer {
private:
    char* data_;
    size_t size_;

public:
    // 拷贝构造：深拷贝（慢）
    Buffer(const Buffer& other) {
        size_ = other.size_;
        data_ = new char[size_];
        std::memcpy(data_, other.data_, size_);
    }

    // 移动构造：转移所有权（快）
    Buffer(Buffer&& other) noexcept {
        data_ = other.data_;
        size_ = other.size_;
        other.data_ = nullptr;  // 清空源对象
        other.size_ = 0;
    }

    ~Buffer() { delete[] data_; }
};

// 使用移动语义
Buffer createBuffer() {
    Buffer buf(1024);
    return buf;  // 自动移动，不拷贝
}

std::vector<Buffer> buffers;
buffers.push_back(std::move(buf));  // 显式移动
```

**何时使用移动**：
- 返回大对象时（编译器自动优化）
- 转移容器所有权时
- 实现swap时

#### 4.3 auto与类型推导
```cpp
// auto：让编译器推导类型
auto x = 10;                    // int
auto s = std::string("hello");  // std::string
auto ptr = std::make_unique<Device>();  // std::unique_ptr<Device>

// 迭代器简化
std::map<int, Recipe> recipes;

// 旧写法
for (std::map<int, Recipe>::iterator it = recipes.begin();
     it != recipes.end(); ++it) {
    // ...
}

// 新写法
for (auto it = recipes.begin(); it != recipes.end(); ++it) {
    // ...
}

// 范围for（更简洁）
for (const auto& [id, recipe] : recipes) {  // C++17结构化绑定
    std::cout << "ID: " << id << ", Name: " << recipe.name() << "\n";
}
```

#### 4.4 nullptr与类型安全
```cpp
// 旧代码
Device* device = NULL;  // NULL是宏，值为0

// 现代C++
Device* device = nullptr;  // 类型安全的空指针

// 为什么重要？
void func(int x);
void func(Device* ptr);

func(NULL);     // 歧义！调用func(int)
func(nullptr);  // 明确调用func(Device*)
```

#### 5.1 线程基础

```cpp
#include <thread>

// 创建线程
void workerFunction(int id) {

int main() {
    std::thread t1(workerFunction, 1);
    std::thread t2(workerFunction, 2);

    t1.join();  // 等待线程结束
    t2.join();

    return 0;
}

// 用Lambda

```

#### 5.2 线程安全与互斥锁
```cpp
#include <mutex>

class ThreadSafeCounter {
private:
    int count_ = 0;
    mutable std::mutex mutex_;  // mutable允许在const函数中修改

public:
    void increment() {
        std::lock_guard<std::mutex> lock(mutex_);  // RAII锁
        ++count_;
    }

    int get() const {
        std::lock_guard<std::mutex> lock(mutex_);
        return count_;
    }
};

// 死锁示例（避免）
std::mutex mtx1, mtx2;

void badFunction1() {
    std::lock_guard<std::mutex> lock1(mtx1);
    std::lock_guard<std::mutex> lock2(mtx2);  // 可能死锁
}

void badFunction2() {
    std::lock_guard<std::mutex> lock2(mtx2);
    std::lock_guard<std::mutex> lock1(mtx1);  // 顺序相反！
}

// 正确做法：统一加锁顺序，或用std::lock
void goodFunction() {
    std::lock(mtx1, mtx2);  // 同时锁定
    std::lock_guard<std::mutex> lock1(mtx1, std::adopt_lock);
    std::lock_guard<std::mutex> lock2(mtx2, std::adopt_lock);
}
```

#### 5.3 Qt线程模型
```cpp
// Qt推荐：moveToThread模式（项目中使用的）
class Worker : public QObject {
    Q_OBJECT

public slots:
    void doWork() {
        // 这个函数在子线程中执行
        emit resultReady("Work done");
    }

signals:
    void resultReady(const QString& result);
};

// 使用
QThread* thread = new QThread;
Worker* worker = new Worker;

worker->moveToThread(thread);  // 移动到子线程

connect(thread, &QThread::started, worker, &Worker::doWork);
connect(worker, &Worker::resultReady, this, &MainWindow::handleResult);
connect(thread, &QThread::finished, worker, &QObject::deleteLater);

thread->start();  // 启动线程
```

**Qt线程规则**：
1. **QObject有线程亲和性**：对象属于创建它的线程
2. **信号槽跨线程自动排队**：Qt::QueuedConnection
3. **不要在子线程操作UI**：只能在主线程
4. **moveToThread后不能有父对象**
